## Files

| File | What it is |
|---|---|
| `index.html` | The whole website (text, design and form in one file) |

| `.nojekyll` | Tells GitHub to publish the files as they are |
| `README.md` | These instructions |

## Publish on GitHub Pages (free)

1. Sign in at https://github.com (create a free account if needed).
2. Click **+** (top right) → **New repository**.
   - Name it **`yourusername.github.io`** (replace with your GitHub username) for the address
     `https://yourusername.github.io`, or any name such as `software` for
     `https://yourusername.github.io/software`.
   - Choose **Public**, then **Create repository**.
3. On the new repository page click **uploading an existing file**.
4. Drag in `index.html`, `favicon.svg`, `README.md` and `.nojekyll`, then click **Commit changes**.
   - `.nojekyll` is a hidden file on some computers. If you can't see it, it's fine to skip it.
5. Go to **Settings → Pages**. Under *Build and deployment* choose
   **Source: Deploy from a branch**, **Branch: main**, folder **/ (root)**, then **Save**.
6. Wait 1–2 minutes and refresh. The site address appears at the top of the Pages settings.
   Share that link with clients, on WhatsApp, Facebook or printed on your visiting card.

## Changing the text later

1. Open the repository on GitHub and click `index.html`.
2. Click the pencil icon (**Edit**).
3. Use **Ctrl + F** to find the words you want to change (for example a phone number or price).
4. Click **Commit changes**. The live site updates in about a minute.
