Questions

Common questions

Do I need internet to use the software?

No. The software runs fully on your computer. You only need internet if you want to contact me on WhatsApp.

Is my data safe?

Your data is stored only on your own computer and is never uploaded anywhere. The software has a password login, and you can make a backup copy any time from the Backup page.

What happens after the 30-day trial?

The software asks for a software key. Contact me to buy one, enter it in Settings, and continue with all your data in place.

Which computers does it work on?

Windows and Mac computers. I help with installation and first-time setup.

Can you build software for our organisation?

Yes. Any kind of software for an organisation can be developed: schools, offices, NGOs, shops, hostels and more. Tell me how you work and I will build around it.

Can you add features to the existing software?

Yes. Many features in the Church Management System, such as departments, events and date-range reports, were added at clients' request. Tell me what you need.

Will I get training and support?

Yes. You get help with setup, an illustrated user manual (for the Church Management System), and direct support by phone or WhatsApp.
